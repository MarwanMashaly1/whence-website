Privacy policy

Whence collects nothing about you

Effective October 29, 2026 · Last updated October 29, 2026

In short
  • Whence has no servers, no accounts and no analytics. It never sends anything it sees to the developer or to anyone else.
  • What it captures on a page stays in that browser tab's memory and is discarded when the tab is closed or reloaded.
  • The only things it saves are your two settings, kept in your browser.
  • Data leaves the extension only when you copy it or export a file yourself.

This policy describes the Whence browser extension ("Whence", "the extension") for Chrome and other Chromium browsers. Whence is a developer tool: it shows which network request, list item and JSON field a value on a web page came from, and which requests a click made.

What Whence reads, and only where you turn it on

Whence runs only on sites you enable from its popup, or on a single tab when you start it there with "this tab only". On those pages, to do its job, it reads:

  • the network requests the page makes and their responses: URLs, methods, status codes, headers and bodies (including WebSocket and server-sent event messages);
  • the page's content: the text and attributes of the element under your pointer, and data the page embeds in its HTML or keeps in its own localStorage, sessionStorage or IndexedDB;
  • that you clicked, submitted a form, pressed Enter, typed in a field, changed a selection or went back or forward, so it can tell which requests followed. It does not record what you type;
  • with DevTools open on the tab, the requests listed in DevTools' Network panel for that tab.

This can include personal or sensitive information that the website itself shows you or exchanges with its servers, such as account details or authentication tokens. Whence processes it only inside your browser, only to show you where values came from, and never transmits it.

What Whence stores

  • Captured requests and page data are kept in memory in the tab where they were captured. They are not written to disk and are gone when you close or reload the tab, or leave the page.
  • Your settings (whether secrets are redacted in copies and exports, and what a click does while inspecting) are saved with chrome.storage.local in your browser.
  • Requests read from DevTools are held briefly in the extension's background memory (the last 300 per tab) to pass them to the page you're inspecting, and dropped when the tab closes.
  • Temporary tab state (the list of frames on the current tab, and which request you opened in the side panel) is kept with chrome.storage.session, which the browser clears when it closes.

What leaves your browser

Nothing, unless you do it:

  • Copy and export. When you copy a request (as text or cURL) or export JSON or a HAR file, it goes to your clipboard or a file you choose. Secrets such as authorization headers, cookies, tokens and password fields are replaced by default; you can turn this off in the settings.
  • "Load earlier data". In "this tab only" mode, Whence can list requests the page made before it started. If you press "Load earlier data", the page requests those same URLs again from the same website, exactly as the page did. No other site is contacted.

Whence makes no other network requests. Its fonts and icons are bundled with the extension.

Sharing and selling

Whence does not sell, rent, share or transfer any user data to anyone. The developer never receives any data from the extension.

Limited use

The use of information Whence handles complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide Whence's single purpose, showing where values on a page came from and which requests an action made. It is not used for advertising, not used to determine creditworthiness or for lending, not transferred to third parties, and not read by any person.

Permissions and why Whence needs them

activeTab
Run Whence on the current tab when you start it there, without access to any other site.
scripting
Add Whence's scripts to the pages you enable, so it can see their requests and the element under your pointer.
Site access (optional)
Granted per site, only when you enable a site. Lets Whence start with the page, so it sees requests from the moment the page loads. You can remove it at any time from the popup or Chrome's extension settings.
storage
Save your settings and temporary tab state, as described above.
sidePanel
Show the request list and click timeline in Chrome's side panel.

Children

Whence is a tool for software developers and is not directed at children. It does not knowingly collect information from anyone, including children.

This website

This website sets no cookies and runs no analytics. It loads its fonts from Google Fonts, which receives your IP address as part of serving them.

Changes to this policy

If Whence ever changes how it handles data, this page will be updated before the change is released, and the date above will change. A change that would send data off your device would be announced in the extension's release notes and require your consent.
